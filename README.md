### 📱 [NoteView AI](https://noteviewai.pages.dev/) — *Live Android App*
> **The only Android app that lets you RUN Jupyter Notebooks — not just view them.**

```
Problem  →  Students & data scientists couldn't run .ipynb files on mobile. Every app was read-only.
Solution →  Built NoteView AI: a full Jupyter execution environment in your pocket.
Built with →  Cursor AI + Antigravity framework. Shipped to production independently.
```

**🔥 What it does:**
- ✅ **Execute Python code cells** inside `.ipynb` files — fully offline, local kernel on-device
- ✅ **Full Kernel Control** — Start, Stop, Reset with one tap. Kill infinite loops instantly
- ✅ **Data Science Ready** — NumPy, Pandas, Matplotlib, Scikit-learn built-in. Run real ML on your phone
- ✅ **Python Compiler + Jedi Autocomplete** — Write and run `.py` scripts with smart suggestions
- ✅ **AI Code Assistant** — Llama 3.3 (70B) for deep explanations + Llama 3.1 (8B) for speed
- ✅ **PDF Export, Snippet Manager, Themes** — Dark/Light/System, syntax highlighting, pro UI
